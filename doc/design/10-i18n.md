# 10. 国際化 (日本語 / 英語のランタイム切替)

[← 目次に戻る](../design.md)

---

## 10.1 要件

- メニュー・UI の言語を**日本語 / 英語で切り替えられる**。
- **アプリの再起動を必要としない**。切り替えた瞬間に UI 全体が変わる。
- 初回起動時は OS のロケールから推定し、以後はユーザー設定を優先する。
- 字幕エフェクトプラグインの表示名・パラメータ名も切替に追従できる。

## 10.2 翻訳リソース

Qt Linguist 方式を採用する。

```
i18n/
├── yave_ja.ts        翻訳ソース (XML、VCS 管理対象)
└── yave_en.ts
```

`.ts` → `.qm` の変換と `qrc` への埋め込みは CMake が行う。

```cmake
# src/app/CMakeLists.txt
qt_add_translations(yave_app
    TS_FILES
        ${CMAKE_SOURCE_DIR}/i18n/yave_ja.ts
        ${CMAKE_SOURCE_DIR}/i18n/yave_en.ts
    RESOURCE_PREFIX "/i18n"
    LUPDATE_OPTIONS -no-obsolete -locations none
)
```

- `RESOURCE_PREFIX "/i18n"` により、`.qm` が `:/i18n/yave_ja.qm` として埋め込まれる。
- `-no-obsolete` で使われなくなった文字列を `.ts` から除去する。
- `-locations none` で行番号情報を落とす。これを付けないと、
  コードを 1 行足しただけで `.ts` に巨大な diff が出て、翻訳作業のレビューが困難になる。

翻訳の更新は以下で行う。

```bash
cmake --build build --target yave_app_lupdate
```

### 10.2.1 ソース文字列の言語

**ソースコード中の文字列 (`tr()` の引数) は英語で書く。**
`yave_en.ts` は基本的に空 (ソース = 訳文) となり、`yave_ja.ts` に日本語訳が入る。

> **日本語をソース文字列にしない理由**: `tr("ファイルを開く")` と書くと、
> ソースが Shift_JIS で保存された環境でビルドが壊れる、
> 英語圏の開発者が読めない、Linguist 上でソース欄が日本語になり
> 他言語への展開時に二重翻訳になる、といった問題が出る。

## 10.3 コーディング規約

### 10.3.1 必須ルール

| ルール | 例 |
|---|---|
| C++ の UI 文字列は `tr()` | `setWindowTitle(tr("Timeline"))` |
| QML の UI 文字列は `qsTr()` | `text: qsTr("Export")` |
| 非 QObject クラスでは `QCoreApplication::translate()` | `QCoreApplication::translate("Export", "Rendering...")` |
| 変数への文字列連結で文を作らない | ✗ `tr("Deleted ") + n + tr(" clips")` |
| 引数は `%1` で埋め込む | ✓ `tr("Deleted %n clip(s)", "", n)` |
| 曖昧な語には disambiguation を付ける | `tr("Track", "timeline layer")` / `tr("Track", "audio recording")` |
| 翻訳者向けの注記は `//:` コメント | `//: Shown in the export progress dialog` |

### 10.3.2 複数形

英語と日本語では複数形の扱いが異なる。`%n` 形式を使う。

```cpp
statusLabel->setText(tr("%n clip(s) selected", "", selectedCount));
```

- 英語: `%n clip selected` / `%n clips selected` (Linguist が 2 フォーム要求)
- 日本語: `%n 個のクリップを選択中` (1 フォームのみ)

Linguist が言語ごとに必要なフォーム数を自動で提示する。

### 10.3.3 禁止パターン

```cpp
// ✗ 悪い例: 文を組み立てている。語順が言語で変わるため翻訳不能。
QString msg = tr("Cannot open ") + fileName + tr(" because ") + reason;

// ✓ 良い例
QString msg = tr("Cannot open %1: %2").arg(fileName, reason);
```

```cpp
// ✗ 悪い例: リテラルを直接 UI へ
button->setText("Export");

// ✓ 良い例
button->setText(tr("Export"));
```

`clang-tidy` のカスタムチェック、または簡易な grep ベースの CI チェックで
`setText("` `setWindowTitle("` `setToolTip("` といったパターンを検出して落とす。

## 10.4 LanguageManager

```cpp
// src/i18n/LanguageManager.h
namespace yave {

class LanguageManager : public QObject
{
    Q_OBJECT
    Q_PROPERTY(QString currentLanguage READ currentLanguage NOTIFY languageChanged)
    Q_PROPERTY(QStringList availableLanguages READ availableLanguages CONSTANT)
    QML_ELEMENT
    QML_SINGLETON

public:
    static LanguageManager& instance();

    /// アプリ起動直後、QML エンジン生成前に呼ぶ。
    ///   1. QSettings から保存済みロケールを読む
    ///   2. 無ければ QLocale::system() から推定 (ja_* -> "ja"、それ以外 -> "en")
    ///   3. 該当する .qm をロードして installTranslator
    void initialize();

    /// QML エンジンを登録する。retranslate() を呼ぶために必要。
    void setQmlEngine(QQmlEngine* engine) { qmlEngine_ = engine; }

    QString     currentLanguage() const { return current_; }     // "ja" / "en"
    QStringList availableLanguages() const { return {"ja", "en"}; }

    /// 言語の表示名 (その言語自身での表記)
    Q_INVOKABLE QString displayName(const QString& code) const;  // "日本語" / "English"

    /// ★ ランタイム切替。アプリ再起動不要。
    Q_INVOKABLE void setLanguage(const QString& code);

    /// プラグインが同梱する翻訳を登録する (10.7)
    void registerPluginTranslations(const QString& dir, const QString& prefix);
    void unregisterPluginTranslations(const QString& prefix);

    /// 翻訳キーを解決する。キーが翻訳テーブルに無ければキー自身を返す。
    /// ISubtitleEffect::displayName() などが返す値の解決に使う。
    static QString translateKey(const QString& key,
                                const QString& context = QStringLiteral("Plugin"));

signals:
    void languageChanged();

private:
    LanguageManager() = default;
    bool loadTranslatorsFor(const QString& code);
    void removeAllTranslators();

    QString                                    current_;
    std::unique_ptr<QTranslator>               appTranslator_;
    std::unique_ptr<QTranslator>               qtBaseTranslator_;
    std::vector<std::unique_ptr<QTranslator>>  pluginTranslators_;
    struct PluginTrSource { QString dir; QString prefix; };
    std::vector<PluginTrSource>                pluginSources_;
    QQmlEngine*                                qmlEngine_ = nullptr;
};

} // namespace yave
```

### 10.4.1 initialize()

```cpp
void LanguageManager::initialize()
{
    QSettings settings;
    QString code = settings.value(QStringLiteral("ui/language")).toString();

    if (code.isEmpty()) {
        // OS ロケールから推定
        const QLocale sys = QLocale::system();
        code = (sys.language() == QLocale::Japanese) ? QStringLiteral("ja")
                                                     : QStringLiteral("en");
    }
    if (!availableLanguages().contains(code))
        code = QStringLiteral("en");

    current_ = code;
    loadTranslatorsFor(code);
}
```

### 10.4.2 setLanguage() — ランタイム切替の中核

```cpp
void LanguageManager::setLanguage(const QString& code)
{
    if (code == current_ || !availableLanguages().contains(code))
        return;

    // (1) 既存のトランスレータをすべて外す
    removeAllTranslators();

    // (2) 新しい言語のトランスレータをインストール
    if (!loadTranslatorsFor(code)) {
        // 失敗したら元に戻す
        loadTranslatorsFor(current_);
        return;
    }
    current_ = code;

    // (3) 設定を保存
    QSettings().setValue(QStringLiteral("ui/language"), code);

    // (4) QML の qsTr() バインディングを再評価させる
    if (qmlEngine_)
        qmlEngine_->retranslate();

    // (5) Widgets 側へ LanguageChange イベントを送る
    //     QCoreApplication::installTranslator が既に全 QWidget へ
    //     LanguageChange を送っているが、明示的に送っておく方が確実。
    for (QWidget* w : QApplication::topLevelWidgets())
        QCoreApplication::sendEvent(w, new QEvent(QEvent::LanguageChange));

    // (6) 自前で保持している文字列 (動的生成した QAction 等) の更新を通知
    emit languageChanged();
}
```

### 10.4.3 loadTranslatorsFor()

**Qt 標準ダイアログ用の `qtbase_<lang>.qm` も一緒に差し替える。**
これを忘れると、ファイルダイアログの「開く」「キャンセル」だけが
前の言語のまま残る。

```cpp
bool LanguageManager::loadTranslatorsFor(const QString& code)
{
    // --- アプリ本体 ---
    appTranslator_ = std::make_unique<QTranslator>();
    const QString appQm = QStringLiteral(":/i18n/yave_%1.qm").arg(code);
    if (appTranslator_->load(appQm)) {
        QCoreApplication::installTranslator(appTranslator_.get());
    } else if (code != QLatin1String("en")) {
        // en はソース文字列がそのまま使われるので .qm が無くても正常
        qCWarning(lcI18n) << "Failed to load translation:" << appQm;
        appTranslator_.reset();
        return false;
    } else {
        appTranslator_.reset();
    }

    // --- Qt 標準ダイアログ / ウィジェット ---
    qtBaseTranslator_ = std::make_unique<QTranslator>();
    const QString qtDir = QLibraryInfo::path(QLibraryInfo::TranslationsPath);
    if (qtBaseTranslator_->load(QStringLiteral("qtbase_%1").arg(code), qtDir)) {
        QCoreApplication::installTranslator(qtBaseTranslator_.get());
    } else {
        qtBaseTranslator_.reset();   // 見つからなくても致命的ではない
    }

    // --- プラグイン同梱翻訳 ---
    for (const PluginTrSource& src : pluginSources_) {
        auto tr = std::make_unique<QTranslator>();
        if (tr->load(QStringLiteral("%1_%2").arg(src.prefix, code), src.dir)) {
            QCoreApplication::installTranslator(tr.get());
            pluginTranslators_.push_back(std::move(tr));
        }
    }
    return true;
}

void LanguageManager::removeAllTranslators()
{
    for (auto& t : pluginTranslators_)
        QCoreApplication::removeTranslator(t.get());
    pluginTranslators_.clear();

    if (qtBaseTranslator_) {
        QCoreApplication::removeTranslator(qtBaseTranslator_.get());
        qtBaseTranslator_.reset();
    }
    if (appTranslator_) {
        QCoreApplication::removeTranslator(appTranslator_.get());
        appTranslator_.reset();
    }
}
```

## 10.5 QML 側の追従

`QQmlEngine::retranslate()` を呼ぶだけで、`qsTr()` を含むバインディングが
すべて再評価される。**QML 側は追加の対応を必要としない。**

```qml
// src/app/qml/MainWindow.qml
import QtQuick
import QtQuick.Controls
import Yave 1.0

ApplicationWindow {
    id: root
    title: qsTr("YetAnotherVideoEditor")

    menuBar: MenuBar {
        Menu {
            title: qsTr("&File")
            Action { text: qsTr("New Project");  onTriggered: projectController.newProject() }
            Action { text: qsTr("Open...");      onTriggered: projectController.openDialog() }
            Action { text: qsTr("Save");         onTriggered: projectController.save() }
            MenuSeparator {}
            Action { text: qsTr("Export...");    onTriggered: exportDialog.open() }
        }
        Menu {
            title: qsTr("&Edit")
            Action { text: qsTr("Undo"); enabled: undoStack.canUndo }
            Action { text: qsTr("Redo"); enabled: undoStack.canRedo }
        }
        Menu {
            title: qsTr("&Timeline")
            Action { text: qsTr("Add Video Track");    onTriggered: editController.addTrack("video") }
            Action { text: qsTr("Add Audio Track");    onTriggered: editController.addTrack("audio") }
            Action { text: qsTr("Add Subtitle Track"); onTriggered: editController.addTrack("subtitle") }
            MenuSeparator {}
            Action { text: qsTr("Import Subtitles (SRT)..."); onTriggered: srtImportDialog.open() }
        }
        Menu {
            title: qsTr("&Language")
            // 言語切替メニュー。ここも qsTr で書かれているので自身も切り替わる
            Repeater {
                model: LanguageManager.availableLanguages
                delegate: MenuItem {
                    text: LanguageManager.displayName(modelData)
                    checkable: true
                    checked: LanguageManager.currentLanguage === modelData
                    onTriggered: LanguageManager.setLanguage(modelData)
                }
            }
        }
    }
}
```

> **`LanguageManager` を QML シングルトンとして公開する**ことで、
> QML から直接切替を呼べる。`QML_ELEMENT` + `QML_SINGLETON` マクロと
> `qt_add_qml_module` の組み合わせで自動登録される。

### 10.5.1 QML で追従しないケース

`qsTr()` の外で作った文字列は自動更新されない。

```qml
// ✗ property に代入した時点で固定される
property string label: qsTr("Ready")     // これは実は追従する (バインディング)

// ✗ JavaScript で一度だけ組み立てた文字列は追従しない
Component.onCompleted: {
    myText.text = qsTr("Ready")          // 追従しない
}

// ✓ バインディングで書く
Text { text: qsTr("Ready") }             // 追従する
```

動的に構築するリストモデルの表示文字列は、`languageChanged` シグナルを
受けてモデルをリセットする。

```qml
Connections {
    target: LanguageManager
    function onLanguageChanged() { effectListModel.refreshDisplayNames() }
}
```

## 10.6 Widgets 側の追従

`PluginWindow` のような `QWidget` 派生クラスは `changeEvent` を実装する。

```cpp
// src/plugin/PluginWindow.cpp
void PluginWindow::changeEvent(QEvent* e)
{
    if (e->type() == QEvent::LanguageChange)
        retranslateUi();
    QWidget::changeEvent(e);
}

void PluginWindow::retranslateUi()
{
    // プラグイン名自体は翻訳しないが、付随する UI は翻訳する
    bypassButton_->setText(tr("Bypass"));
    presetLabel_->setText(tr("Preset:"));
    resetButton_->setToolTip(tr("Reset all parameters to default"));
}
```

### 10.6.1 動的生成した QAction

コードで動的に作った `QAction` / `QMenu` は `LanguageChange` を受け取らないため、
明示的に再設定する。

```cpp
class EffectContextMenu : public QMenu
{
public:
    explicit EffectContextMenu(QWidget* parent) : QMenu(parent)
    {
        buildActions();
        connect(&LanguageManager::instance(), &LanguageManager::languageChanged,
                this, &EffectContextMenu::retranslate);
    }

private:
    void buildActions()
    {
        addAction_    = addAction(tr("Add Effect..."));
        removeAction_ = addAction(tr("Remove Effect"));
        resetAction_  = addAction(tr("Reset Parameters"));
    }

    void retranslate()
    {
        addAction_   ->setText(tr("Add Effect..."));
        removeAction_->setText(tr("Remove Effect"));
        resetAction_ ->setText(tr("Reset Parameters"));
    }

    QAction* addAction_ = nullptr;
    QAction* removeAction_ = nullptr;
    QAction* resetAction_ = nullptr;
};
```

### 10.6.2 タイムラインの列見出し

`TimelineModel` (`QAbstractItemModel`) の `headerData()` は
`tr()` を毎回呼ぶ実装にし、`languageChanged` で
`headerDataChanged()` を発火させる。

```cpp
QVariant TimelineModel::headerData(int section, Qt::Orientation o, int role) const
{
    if (role != Qt::DisplayRole || o != Qt::Horizontal) return {};
    switch (section) {
    case 0: return tr("Track");
    case 1: return tr("Type");
    case 2: return tr("Clips");
    default: return {};
    }
}

// コンストラクタで
connect(&LanguageManager::instance(), &LanguageManager::languageChanged, this, [this] {
    emit headerDataChanged(Qt::Horizontal, 0, columnCount() - 1);
    emit dataChanged(index(0, 0), index(rowCount() - 1, columnCount() - 1),
                     {Qt::DisplayRole, Qt::ToolTipRole});
});
```

## 10.7 プラグイン文字列の翻訳

### 10.7.1 方式

`ISubtitleEffect::displayName()` と `ParameterSchema` の
`displayNameKey` / `tooltipKey` / `enumKeys` は、
**翻訳キー**を返してもよい設計にする。

```cpp
// プラグイン側の実装例
QString GlitchEffect::displayName() const
{
    return QStringLiteral("effect.glitch.name");     // 翻訳キー
}

yave::sdk::ParameterSchema GlitchEffect::parameterSchema() const
{
    return {
        { "intensity", "effect.glitch.intensity", ParamType::Double, 0.5, 0.0, 1.0 },
        { "seed",      "effect.glitch.seed",      ParamType::Int,    0,   0,   99999 },
    };
}
```

プラグインは自身の `.qm` を同梱する。

```
plugins/subtitle/
├── glitch.dll
├── glitch_ja.qm
└── glitch_en.qm
```

ファクトリで接頭辞を宣言する。

```cpp
static const yave::sdk::SubtitleEffectFactoryV1 kFactory = {
    yave::sdk::kSubtitleEffectApiVersion,
    "com.example.effects",
    "Example Effects",
    "1.0.0",
    "glitch",                    // translationQmPrefix -> glitch_ja.qm / glitch_en.qm
    &effectCount, &createEffect, &destroyEffect, &shutdown
};
```

### 10.7.2 解決

```cpp
QString LanguageManager::translateKey(const QString& key, const QString& context)
{
    // QTranslator は installTranslator された順の逆順に問い合わされる。
    // プラグイン翻訳は後からインストールされているので優先される。
    const QString translated =
        QCoreApplication::translate(context.toUtf8().constData(),
                                    key.toUtf8().constData());

    // 翻訳が見つからなければ translate() はキー自身を返す。
    // その場合は「翻訳キーではなく、そのまま表示すべき文字列だった」とみなす。
    return translated;
}
```

**フォールバックが自然に働く**のがこの設計の利点。
翻訳を提供しないプラグインが `displayName()` で `"Glitch"` をそのまま返しても、
`translateKey("Glitch")` は `"Glitch"` を返す。特別扱いのコードが要らない。

UI 側:

```cpp
// src/app/models/EffectStackModel.cpp
QVariant EffectStackModel::data(const QModelIndex& idx, int role) const
{
    const auto& inst = stack_->at(idx.row());
    if (role == DisplayNameRole) {
        if (inst.missing)
            return tr("Missing: %1").arg(inst.effectId);
        return LanguageManager::translateKey(inst.effect->displayName());
    }
    // ...
}
```

### 10.7.3 対象外とするもの

以下はプラグイン作者の管轄であり、本アプリの言語切替の対象外とする。
これを設計書に明記しておく。

- **VST3 プラグインの独自 GUI 内の文字列** — プラグインが自前で描画している
- **AviUtl フィルタの設定ウィンドウ内の文字列** — 同上
- **AviUtl フィルタのトラックバー名 (`track_name`)** — DLL に埋め込まれた
  固定文字列であり、大半が日本語。そのまま表示する

VST3 は `IEditController::getParameterInfo()` の `title` を返すが、
これも言語切替に追従しない (VST3 仕様に言語指定の口が無い)。

## 10.8 ロケール依存フォーマット

| 対象 | 方針 |
|---|---|
| **タイムコード** | **ロケール非依存**。常に `HH:MM:SS:FF` (ドロップフレーム時は `HH:MM:SS;FF`) |
| フレーム番号 | 桁区切りなし。`123456` |
| 日付・時刻 (保存日時等) | `QLocale::toString(QDateTime, QLocale::ShortFormat)` |
| ファイルサイズ | `QLocale::formattedDataSize()` |
| パーセンテージ | `QLocale::toString(value * 100, 'f', 1) + "%"` |
| 小数値 (ゲイン等) | `QLocale::toString(double, 'f', 2)`。ただし**入力欄では `.` と `,` の両方を受け付ける** |

> **タイムコードをロケール非依存にする理由**: タイムコードは業界標準の表記であり、
> 現場では言語を問わず `01:23:45:12` の形で読み書きされる。
> ここをロケール化すると、他の編集ソフトや納品仕様書との突き合わせができなくなる。

```cpp
// src/util/TimecodeFormat.h
QString formatTimecode(int64_t frame, const Rational& tb, bool dropFrame);
std::optional<int64_t> parseTimecode(const QString& s, const Rational& tb);
```

## 10.9 フォント

日本語 UI では、システムフォントに日本語グリフが無いと豆腐 (□) になる。

```cpp
// src/app/main.cpp
void applyUiFont(const QString& langCode)
{
    QFont f = QApplication::font();
#if defined(Q_OS_WIN)
    if (langCode == QLatin1String("ja"))
        f.setFamilies({"Yu Gothic UI", "Meiryo UI", "MS UI Gothic", "Segoe UI"});
    else
        f.setFamilies({"Segoe UI", "Yu Gothic UI"});
#elif defined(Q_OS_MACOS)
    if (langCode == QLatin1String("ja"))
        f.setFamilies({"Hiragino Sans", "Hiragino Kaku Gothic ProN", "SF Pro Text"});
    else
        f.setFamilies({"SF Pro Text", "Helvetica Neue", "Hiragino Sans"});
#endif
    QApplication::setFont(f);
}
```

`setLanguage()` からもこれを呼ぶ。

### 10.9.1 UI フォントと字幕フォントは分離する

**`QApplication::font()` の変更が字幕レンダリングに影響してはならない。**
`SubtitleStyle::fontFamily` は常に明示指定であり、システムフォントを参照しない。

> 言語を切り替えたら動画に焼き込まれる字幕のフォントまで変わった、
> という事故を構造的に防ぐ。

字幕用の既定フォントは、UI 言語ではなく**プロジェクト設定**として持つ。

```cpp
struct ProjectSettings {
    QString defaultSubtitleFontFamily = QStringLiteral("Noto Sans JP");
};
```

## 10.10 レイアウトへの配慮

日本語 → 英語で文字列長が 1.5〜2 倍になることがある。

| 対策 | 内容 |
|---|---|
| 固定幅を避ける | ボタン幅は `implicitWidth` ベース。QML では `Layout.preferredWidth` を使わず `Layout.fillWidth` |
| 省略表示 | `Text { elide: Text.ElideRight }` を既定にする |
| ツールチップ | 省略された場合は完全な文字列をツールチップに出す |
| テスト | 疑似ロケール (`yave_xx.qm` に文字列を 1.4 倍に伸ばしたもの) を CI で生成し、レイアウト崩れを検出 |

```cmake
# CI 用: 疑似ロケール生成
```

## 10.11 翻訳の運用

### 10.11.1 未翻訳の検出

```bash
lconvert -if ts -i i18n/yave_ja.ts -of ts -o /dev/null --verbose
```

CI で `.ts` 内の `type="unfinished"` の数をカウントし、
一定数を超えたら警告を出す (ビルドは通す)。

### 10.11.2 翻訳キーの命名

プラグイン向けの翻訳キーは階層的に命名する。

```
effect.<plugin>.<effect>.name
effect.<plugin>.<effect>.param.<key>
effect.<plugin>.<effect>.param.<key>.tooltip
error.ai.<code>
status.ai.<code>
warning.<domain>.<code>
```

アプリ本体の `tr()` は英語ソース文字列をそのまま使うため、キー形式にはしない。
**キー形式を使うのはプラグイン境界を越える文字列**、および
**エンジン層 (`yave_ai` 等) が UI を知らずに返すメッセージ**とする
(前者はプラグインのソース文字列を lupdate で収集できないため、
後者は `yave_ai` が Qt Widgets/QML を include しないため)。

AIトラック ([13 章](13-ai-track.md)) が追加するキー:

```
error.ai.storyboard.tooLarge          応答サイズ / カット数の上限超過
error.ai.storyboard.invalidJson
error.ai.storyboard.schemaMismatch
error.ai.storyboard.disallowedField   モデルが許可リスト外の値を指定した
error.ai.storyboard.continuityCycle   連続性チェーンが循環している
error.ai.storyboard.noApprovedCuts    選択範囲に生成対象が無い
error.ai.storyboard.bibleKeyConflict  Story Bible の key 衝突
error.ai.storyboard.emptyPlan

error.ai.cut.noOutputs                出力バインディングが 1 つも無い
error.ai.cut.boundTrackMissing        resolvedTrackId の指すトラックが無い
error.ai.cut.trackTypeMismatch        役割と配置先トラックの型が合わない
error.ai.cut.zeroDuration

status.ai.storyboard.planning
status.ai.storyboard.batchRunning
status.ai.storyboard.orphanedResult   Undo でカットが消えた成果物 (捨てずに保持)
status.ai.storyboard.skippedUnchanged 仕様が変わっていないためスキップ
status.ai.storyboard.blockedByUpstream

warning.export.uncommittedCuts        未生成カットを含む範囲を書き出そうとした
warning.ai.cut.dialogueOverflow       TTS がカット尺を超えた
warning.ai.cut.promptLockStale        ロック後に仕様が変わった
```

### 10.11.3 翻訳経路に載せてはならない文字列

**モデルへ渡すプロンプト、およびモデルが生成したテキストは `tr()` / `qsTr()` を通さない。**

- カメラワーク enum からプロンプト断片への変換は英語固定の
  `resources/ai/camera_phrases.json` から引く。UI ラベルの翻訳とは別系統にする
- Story Bible の `promptFragment`、`StoryBible::promptTemplates`、
  L1 が生成した `description` / `dialogue` はいずれもプロジェクトのデータであり、
  アプリの翻訳リソースではない

> **理由**: UI 言語を日本語に切り替えただけでモデルへ渡る語彙が変わると、
> **同じプロジェクトが環境によって違う絵を出す**。
> 生成結果の再現性は言語設定から独立していなければならない。

### 10.11.4 ボードビューの複数形

カット数を伴うメッセージは `%n` 形式を使う (10.3 の規約どおり)。

```cpp
tr("Reorder %n cut(s)", "", n);          // Undo テキスト
tr("%n cut(s) will be generated", "", n);// バッチ確認ダイアログ
tr("%n cut(s) skipped (unchanged)", "", n);
```

## 10.12 テスト

```cpp
// tests/tst_i18n.cpp
void TestI18n::switchLanguageAtRuntime()
{
    auto& lm = LanguageManager::instance();
    lm.initialize();

    lm.setLanguage("en");
    QCOMPARE(QObject::tr("Export"), QStringLiteral("Export"));

    QSignalSpy spy(&lm, &LanguageManager::languageChanged);
    lm.setLanguage("ja");
    QCOMPARE(spy.count(), 1);
    QCOMPARE(lm.currentLanguage(), QStringLiteral("ja"));
    // yave_ja.ts に "Export" -> "書き出し" が入っている前提
    QCOMPARE(QObject::tr("Export"), QString::fromUtf8("書き出し"));

    // 戻せることも確認
    lm.setLanguage("en");
    QCOMPARE(QObject::tr("Export"), QStringLiteral("Export"));
}

void TestI18n::timecodeIsLocaleIndependent()

    QCOMPARE(formatTimecode(3600, timebase::Fps60, false), QStringLiteral("00:01:00:00"));
}
```
